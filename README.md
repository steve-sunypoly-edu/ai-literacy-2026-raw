# AI Literacy Curriculum Archive

**Steve Schneider** | SUNY AI Fellow for the Public Good | Co-Director, AIX Center at SUNY Polytechnic Institute

*Version: 2026-04-26-2052*

This repository contains the foundational generation transcripts and conceptual development records for the SUNY AI Literacy Curriculum. The work herein operationalizes AI literacy through the **RTW (Reading, Thinking, Writing)** framework—treating generative AI as a medium for literate practice, rather than merely a subject matter.

## 📚 Contents
These Claude.ai design sessions produced two core artifacts:
* **[The Learner's Permit (LP)](artifacts/ai-literacy-learners-permit.html):** A 15-exercise foundational scaffold for AI literacy.
* **[The Agentic License (AL)](artifacts/ai-literacy-commercial-license.html):** A 15-exercise scaffold for agentic AI operation.

### About the Project Context
These materials were developed in alignment with SUNY Board Resolution 2024-64 regarding AI literacy integration across 64 campuses. All materials are open and freely adaptable.
